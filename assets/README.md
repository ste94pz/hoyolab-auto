# HoYoUtils artwork

[HoYoUtils.png](HoYoUtils.png) is the approved project logo, provided by ste94pz
and preserved without modification. It is AI-generated fan artwork inspired by
Mimo, the HoYoLAB mascot, used as an unofficial project illustration. It was
created specifically for this project, rather than downloaded from an artist
or taken from HoyoLab Auto's assets.
